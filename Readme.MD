# TD3 Decentralized

The `Flask.ipynb` Notebook contains two sections:

1. **Training the Model**: The first cell of the notebook is for training the model. It includes all the necessary code and configurations to train the TD3 decentralized model. Running this cell is optional as the `model.pkl` file is already provided in the folder.

2. **Model Prediction API**: The second cell of the notebook is for the API of the model prediction. It provides the interface and functionality to make predictions using the trained model.

The `client.py` file is used to interact with the model prediction API.
